# Issue tracker

This repository tracks work in GitHub Issues.

Repository: https://github.com/HussonAxel/pokemonv1

Use the GitHub CLI for issue operations:

- List: `gh issue list`
- View: `gh issue view <number>`
- Create: `gh issue create`
- Comment: `gh issue comment <number>`
- Close: `gh issue close <number>`

Issues are the canonical work items. Pull requests are not part of the triage queue by default.
